\section{Configuration Format}

\subsection{Linux JSON}

Linux loads JSON at startup and converts it into the same static configuration shape used by MCU targets. JSON is a platform convenience, not a core dependency.

\begin{lstlisting}[caption={Top-level configuration sketch}]
{
  "control_period_ms": 100,
  "sensors": [],
  "actuators": [],
  "zones": [],
  "policy_modifiers": [],
  "fault_detection": {},
  "telemetry": {}
}
\end{lstlisting}

\subsection{MCU Static Configuration}

Embedded builds use a generated or hand-written \texttt{static const thermal\_config\_t}. The JSON parser is not linked into MCU firmware.

\subsection{Validation}

Configuration validation should reject duplicate IDs, references to missing sensors or actuators, zones without sensors, out-of-bounds curve points, invalid PWM limits, and unsupported governor or policy names.

\subsection{Reference Configuration and the MCU Pin Map}

The shipped reference configuration is \texttt{platform/esp32\_idf/configs/} \texttt{esp32-c3-standalone.json}: one step-wise \texttt{soc\_zone}, the four-trip staircase of Section~\ref{sec:zone-mapping}, and a telemetry block. On Linux the daemon parses it at startup. For the MCU build, \texttt{tools/json2static.py} converts the same JSON into a generated \texttt{const thermal\_config\_t G\_THERMAL\_CFG} compiled directly into the firmware --- no JSON parser is linked into MCU images. A round-trip test asserts the generated struct is canonically equal to the same JSON loaded through the Linux parser, so the two configuration paths cannot silently diverge.

Platform pin assignments live in an optional top-level \texttt{mcu\_pinmap} section: a 1-Wire GPIO per sensor, and a PWM GPIO, tach GPIO, and PWM frequency per actuator. \texttt{json2static.py} emits this as a second generated structure alongside \texttt{G\_THERMAL\_CFG}. Because the firmware loops over the declared sensor and actuator counts and indexes the pin map by slot, adding a second fan or probe to the bench rig is a JSON-only change --- no firmware C source is edited.
