\section*{Abstract}

\texttt{thermal-core} is a protocol-agnostic thermal-control core with an automotive IVI reference application. It separates deterministic control policy --- zones, trip points, step-wise and PID governors, fault detection, arbitration --- from platform I/O, so the same C99 control law runs unmodified on Linux, ESP-IDF, and MCU-class targets, bit-for-bit reproducibly. Policy behavior is extended through configured \emph{context modifiers}: typed, non-temperature inputs that shape governor targets and actuator limits without entering the core's control law. The first reference modifier demonstrates this mechanism with an acoustic-aware fan policy driven by vehicle speed.

This draft reflects the implementation as shipped through Stage~16, the final v1 stage: the protocol-agnostic core, the Linux \texttt{thermalcored} daemon, three ESP32-C3 firmware build modes, a hardware-in-the-loop bench bring-up, deterministic cross-platform replay parity, and the figure-regeneration pipeline that renders the scenario plots in the Evaluation section. Post-v1 work is folded in as well: the CH32V003 \texttt{STANDALONE} port, the advisory fan-health detector, and the review-driven control-loop refinements documented in the concept sections. The conceptual and implementation sections are written against the real code. The formal hardware benchmark sweep --- calibrated acoustic and timing measurement on instrumented hardware --- is still pending, so the Evaluation section is marked preliminary and reports only measured results.
